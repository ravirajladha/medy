# Medy - Hospital Management System (PHP MVC)

Medy is a Hospital Management System built with PHP MVC, designed to streamline hospital operations. It provides tools for managing patient records, appointments, staff, and other hospital-related activities, ensuring efficient administration and improved patient care.

## Features

- **Patient Management**: Register, update, and manage patient records, including medical history and contact details.
- **Appointment Scheduling**: Schedule and manage patient appointments with doctors.
- **Staff Management**: Maintain records of hospital staff, including doctors, nurses, and administrators.
- **Billing and Payments**: Generate bills for patients and track payment statuses.
- **MVC Architecture**: Organized codebase using the Model-View-Controller pattern for scalability and maintainability.

## Prerequisites

- PHP >= 7.4
- MySQL or MariaDB
- Apache (e.g., via XAMPP)
- Composer for dependency management
- Git

## Usage

- **Manage Patients**: Add, edit, and view patient records, including medical history.
- **Schedule Appointments**: Book appointments with doctors and view schedules.
- **Handle Staff**: Manage records of doctors, nurses, and administrative staff.
- **Generate Bills**: Create and track patient bills and payments.
